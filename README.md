# Dry Bean Classification and Morphological Discovery

## Project Overview
This project focuses on classifying different varieties of dry beans using data mining and machine learning techniques based on their morphological characteristics.

## Dataset
- Dataset: Dry Bean Dataset
- Source: UCI Machine Learning Repository
- Total Records: 13,611
- Numerical Features: 16
- Target Variable: Class
- Number of Classes: 7

## Project Objectives
- Perform Exploratory Data Analysis (EDA).
- Apply data preprocessing and normalization.
- Perform feature selection and Principal Component Analysis (PCA).
- Analyse similarity and dissimilarity.
- Implement classification algorithms.
- Discover frequent patterns using association rules.
- Perform clustering analysis.
- Design a data warehouse and perform OLAP operations.

## Algorithms Used

### Classification
- Decision Tree
- Rule-Based Classification
- K-Nearest Neighbors (KNN)

### Association Rule Mining
- Apriori
- FP-Growth

### Clustering
- K-Means
- Hierarchical Clustering
- DBSCAN
